B1
☁️ Elegir dónde hospedar el servidor
BÁSICO
Tenés tres opciones reales para hostear el servidor:

Opción A — VPS (recomendado para un servidor serio):
Un VPS es una computadora virtual en un datacenter. Siempre está prendida, tiene IP fija, y podés instalar lo que quieras. Proveedores recomendados para Argentina/Latam: Hostinger VPS (barato, buen soporte en español), Oracle Cloud Free Tier (tiene un VPS gratuito de 4 núcleos y 24GB RAM, ideal para empezar). Para un servidor con 20-30 jugadores necesitás mínimo 4 núcleos y 8GB RAM.

Opción B — Hosting especializado de Minecraft:
Servicios como Aternos (gratuito pero limitado), Bisect Hosting, o Apex Hosting. Más fáciles pero menos control. Aternos no soporta mods Fabric bien ni configuraciones avanzadas.

Opción C — Tu propia PC:
Válido para empezar, pero requiere IP fija o Dynamic DNS, y la PC debe estar prendida siempre. Útil para desarrollo/pruebas, no para producción.
Para este proyecto con todos los sistemas que querés, recomiendo VPS mínimo 6GB RAM / 4 cores. Oracle Cloud Free Tier da exactamente eso gratis.
B2
☕ Instalar Java 21
BÁSICO
Minecraft 1.21.1 requiere Java 21 obligatoriamente. No Java 8, no Java 17. Java 21.

En Linux (VPS Ubuntu/Debian) — comandos en terminal:
# Actualizar el sistema primero
sudo apt update && sudo apt upgrade -y

# Instalar Java 21 (OpenJDK)
sudo apt install openjdk-21-jdk -y

# Verificar la instalación
java -version
# Debe decir: openjdk version "21.x.x"
En Windows: descargar el instalador de adoptium.net → Temurin 21 → instalar con permisos de admin. Verificar con java -version en CMD.
⚠️ Muchos errores de inicio del servidor son por tener Java 17 o Java 8. Siempre verificar la versión antes de continuar.
B3
📦 Descargar e instalar Paper 1.21.1
BÁSICO
Paper es el fork de Spigot con las optimizaciones que mencionamos. No usar Vanilla ni CraftBukkit.
# Crear carpeta del servidor
mkdir ~/servidor && cd ~/servidor

# Descargar Paper 1.21.1 (última build)
# Ir a: https://papermc.io/downloads/paper
# Seleccionar 1.21.1 → Download → copiar link directo
wget -O paper.jar "https://api.papermc.io/v2/projects/paper/versions/1.21.1/builds/ULTIMO/downloads/paper-1.21.1-ULTIMO.jar"

# Renombrar para facilitar el script
mv paper*.jar server.jar
En Windows: descargar el .jar desde papermc.io/downloads/paper, crear una carpeta C:\servidor y poner el .jar ahí.
B4
▶️ Script de inicio + primer arranque
BÁSICO
Crear el script de arranque con las Aikar's Flags — flags de JVM optimizadas para Minecraft. Estas reducen los "garbage collection pauses" (congelones) significativamente.
# Crear el script de inicio (Linux)
nano start.sh

# Pegar esto dentro del archivo:
#!/bin/bash
java -Xms4G -Xmx8G \
  -XX:+UseG1GC \
  -XX:+ParallelRefProcEnabled \
  -XX:MaxGCPauseMillis=200 \
  -XX:+UnlockExperimentalVMOptions \
  -XX:+DisableExplicitGC \
  -XX:+AlwaysPreTouch \
  -XX:G1NewSizePercent=30 \
  -XX:G1MaxNewSizePercent=40 \
  -XX:G1HeapRegionSize=8M \
  -XX:G1ReservePercent=20 \
  -XX:G1HeapWastePercent=5 \
  -XX:G1MixedGCCountTarget=4 \
  -XX:InitiatingHeapOccupancyPercent=15 \
  -XX:G1MixedGCLiveThresholdPercent=90 \
  -XX:G1RSetUpdatingPauseTimePercent=5 \
  -XX:SurvivorRatio=32 \
  -XX:+PerfDisableSharedMem \
  -XX:MaxTenuringThreshold=1 \
  -jar server.jar --nogui

# Guardar (Ctrl+O, Enter, Ctrl+X) y dar permisos
chmod +x start.sh

# Primer arranque (va a fallar — es normal)
./start.sh
El primer arranque genera el archivo eula.txt y se cierra. Eso es correcto.
# Aceptar el EULA
nano eula.txt
# Cambiar: eula=false → eula=true
# Guardar y salir

# Segundo arranque — ahora sí genera el mundo
./start.sh
✦ Si ves "Done (X.Xs)! For help, type 'help'" el servidor está corriendo. Podés escribir comandos directamente en esa terminal.
B5
🔧 Configurar server.properties
BÁSICO
Este archivo controla el comportamiento base del servidor. Se crea automáticamente. Editarlo antes de que entre el primer jugador.
nano server.properties
# ── CONFIGURACIONES IMPORTANTES ──

# Nombre visible en la lista de servidores
motd=\u00a76[ServidorRPG] \u00a7fBienvenido

# Puerto (25565 por defecto, abrir en firewall)
server-port=25565

# Modo online: true = requiere cuenta Mojang legítima
# false = acepta cuentas sin licencia (necesita AuthMe)
online-mode=false

# Máximo de jugadores simultáneos
max-players=50

# CRÍTICO: reducir de 10 a 6 para menos lag
view-distance=6

# Distancia de simulación (mobs, redstone, tick)
simulation-distance=4

# Spawn de mobs por defecto
spawn-monsters=true
spawn-animals=true

# Dificultad: peaceful, easy, normal, hard
difficulty=normal

# Modo de juego por defecto para nuevos jugadores
gamemode=survival

# Whitelist: true = solo jugadores aprobados pueden entrar
white-list=false
⚠️ Si ponés online-mode=false, necesitás instalar AuthMe obligatoriamente antes de abrir al público. Sin AuthMe, cualquiera puede entrar con el nick de otro jugador.
B6
🌐 Abrir el puerto en el firewall
BÁSICO
Por defecto, el VPS bloquea las conexiones entrantes. Hay que abrir el puerto 25565 (TCP) para que los jugadores puedan conectarse.
# Ubuntu/Debian con UFW
sudo ufw allow 25565/tcp
sudo ufw allow 25565/udp
sudo ufw enable
sudo ufw status

# Si usás Oracle Cloud, también abrir en su panel web:
# Networking → Virtual Cloud Network → Security Lists → Add Rule
# Destination Port: 25565, Protocol: TCP
Para conectarse al servidor desde el cliente de Minecraft usar la IP pública del VPS (la que te da el proveedor). Si es en tu propia PC, usar tu IP pública + configurar port forwarding en el router.
# Ver tu IP pública del VPS
curl ifconfig.me

📁 Estructura de carpetas del servidor
BÁSICO
Después del primer arranque exitoso, la carpeta del servidor se ve así. Importa saber dónde va cada cosa.
servidor/
├── plugins/ ← AQUÍ van todos los plugins (.jar)
│ ├── LuckPerms/ ← config de cada plugin en su carpeta
│ └── Essentials/
├── world/ ← Mundo principal (Overworld)
├── world_nether/ ← Nether
├── world_the_end/ ← The End
├── server.properties ← Configuración base
├── paper.yml ← Config avanzada de Paper
├── spigot.yml ← Config de Spigot (herencia)
├── start.sh ← Tu script de inicio
├── server.jar ← El jar de Paper
├── eula.txt ← EULA aceptado
└── logs/ ← Logs de consola
📌 Los mods de Fabric NO van en plugins/. Si usás mods Fabric, necesitás el servidor Fabric. Los plugins de Paper van en plugins/, los mods Fabric van en mods/. Son sistemas distintos.

M1
🔐 Instalar AuthMe Reloaded
MEDIO
¿Cómo se instalan los plugins? Siempre igual: descargar el .jar del plugin → copiarlo en la carpeta plugins/ → reiniciar el servidor. El servidor lo detecta automáticamente y crea su carpeta de configuración.

Descargar AuthMe desde spigotmc.org buscando "AuthMe Reloaded".
# Poner el .jar en la carpeta plugins
cp AuthMe.jar ~/servidor/plugins/

# Reiniciar el servidor (desde la consola del servidor)
stop
./start.sh
Después del reinicio, editar plugins/AuthMe/config.yml:
# plugins/AuthMe/config.yml — claves importantes

DataSource:
  backend: SQLITE # básico, sirve para empezar

settings:
  sessions:
    enabled: true
    timeout: 12 # horas antes de pedir login de nuevo

  security:
    passwordMinLength: 5
    passwordMaxLength: 30
    hashAlgorithm: BCRYPT # el más seguro
✦ Ahora cuando alguien entra por primera vez, no puede moverse hasta usar /register. En siguientes ingresos, /login. Si está en la misma IP, las sesiones lo loguean automáticamente.
M2
🎖️ Instalar y configurar LuckPerms
MEDIO
Descargar desde luckperms.net → versión Bukkit/Paper. Instalar como cualquier plugin.

LuckPerms se configura principalmente desde la interfaz web en editor.luckperms.net o con comandos en consola. Acá los comandos base:
# En la consola del servidor (sin el /)

# Crear grupos
lp creategroup visitante
lp creategroup miembro
lp creategroup estudiante
lp creategroup senior
lp creategroup admin
lp creategroup owner

# Dar permiso a un grupo
lp group miembro permission set essentials.home true
lp group miembro permission set essentials.tpa true
lp group estudiante permission set essentials.fly true

# Hacer que miembro herede permisos de visitante
lp group miembro parent add visitante
lp group estudiante parent add miembro
lp group senior parent add estudiante

# Asignar grupo por defecto a jugadores nuevos
lp group visitante setdefault 100

# Asignar grupo a un jugador específico
lp user Konan set group owner
📌 El peso de grupo (setdefault 100) determina qué grupo se aplica si hay conflicto. Mayor número = mayor prioridad.

🗺️ WorldGuard + WorldEdit (base)
MEDIO
WorldGuard necesita WorldEdit instalado. Descargar ambos desde enginehub.org.

WorldGuard protege regiones. WorldEdit selecciona áreas. Ambos van en plugins/.
# En el juego, con vara de madera seleccionar región:
/wand # te da la vara de WorldEdit
# Click izquierdo: primera esquina
# Click derecho: segunda esquina

# Crear región protegida
/rg define spawn # nombre de la región
/rg flag spawn pvp deny # sin PvP en spawn
/rg flag spawn build deny # nadie puede construir

# Dar acceso de construcción a un grupo
/rg addmember spawn g:admin # grupo admin puede

# Región exclusiva Owner (nadie más puede modificar)
/rg define zona-owner
/rg flag zona-owner build deny
/rg setpriority zona-owner 100
# Solo agregar al owner como member de esa región
/rg addmember zona-owner TuNickOwner

MEDIO

M7
📜 Instalar Skript
MEDIO
Skript es el motor de scripts del servidor. Todo el comportamiento personalizado (exámenes, ascensos de rango, recompensas, comandos custom) vive aquí. Descargar desde github.com/SkriptLang/Skript.
# Los scripts van en plugins/Skript/scripts/
# Crear un script de ejemplo: ascenso.sk

command /rankup:
  trigger:
    if player's group is "visitante":
      set player's group to "miembro"
      send "&aAscendiste a Miembro!" to player
    else:
      send "&cNo cumplís los requisitos." to player

# Recargar scripts sin reiniciar el servidor
sk reload all
📌 Los archivos .sk van en plugins/Skript/scripts/. Podés tener múltiples archivos, uno por sistema. Se recargan en vivo con /sk reload.

🎙️ Simple Voice Chat (Fabric)
AVANZADO
Simple Voice Chat es un mod Fabric, no un plugin de Paper. Requiere que el servidor también corra Fabric. Acá dos opciones:

Opción A (recomendada): Servidor Paper para los plugins, y Simple Voice Chat tiene una versión Bukkit/Paper que funciona sin Fabric.
Opción B: Servidor Fabric puro para los mods, sin plugins de Paper.
# Instalar la versión Bukkit de Simple Voice Chat
# Descargar desde modrinth.com → "Simple Voice Chat" → Bukkit
cp voicechat-bukkit-*.jar ~/servidor/plugins/

# Abrir el puerto UDP del voice chat en el firewall
sudo ufw allow 24454/udp

# plugins/voicechat/voicechat-server.properties
port=24454
max_voice_distance=48.0 # bloques de alcance
crouch_distance_multiplier=0.5 # susurro al agacharse
⚠️ Los jugadores también necesitan instalar el mod Simple Voice Chat en su cliente (versión Fabric para cliente). Sin el mod en cliente, no escuchan nada.

AVANZADO
CC:T es un mod Fabric/Forge, no un plugin. Para usarlo con un servidor Paper, necesitás la versión Forge en un servidor Mohist o configurar un servidor Fabric separado para el "mundo laboratorio".

Descargar desde modrinth.com → "CC: Tweaked".

🤖 Integración de IA (Chatbot real)
AVANZADO
La forma más estable: DiscordSRV + bot de Discord con API de OpenAI/Claude.

Paso 1: Instalar DiscordSRV (plugin Paper) y conectarlo a un servidor de Discord.
Paso 2: Crear un bot de Discord en discord.com/developers.
Paso 3: Programar el bot en Node.js para que escuche mensajes que empiecen con @asistente y los envíe a la API de Claude o OpenAI.
// bot.js — Node.js (simplificado)
// Este bot recibe mensajes de Minecraft via DiscordSRV

client.on('messageCreate', async (msg) => {
  if (!msg.content.startsWith('@asistente')) return;

  const pregunta = msg.content.replace('@asistente', '').trim();

  // Llamar a la API de Claude o OpenAI
  const respuesta = await llamarIA(pregunta);

  // La respuesta vuelve al canal de Discord
  // DiscordSRV la reenvía al chat de Minecraft
  msg.reply(`🤖 ${respuesta}`);
});
📌 El system prompt del bot debe incluir: reglas del servidor, lista de rangos, comandos disponibles, nombre del servidor. Así la IA responde como asistente oficial.

🗺️ Pregenerar el mundo con Chunky
AVANZADO
Antes de abrir el servidor al público, pregenerar los chunks elimina el 90% del lag por exploración. Instalar Chunky desde modrinth.com.
# Generar un radio de 3000 bloques del mundo principal
# Esto puede tardar 20-60 minutos según el hardware
/chunky radius 3000
/chunky world world # nombre del mundo
/chunky start

# Ver progreso
/chunky progress

# Hacer lo mismo para cada mundo
/chunky world rpg-mundo
/chunky radius 5000
/chunky start
✦ Pregenerar es una de las mejores inversiones de tiempo antes del lanzamiento. Un mundo de 3000 bloques de radio ocupa ~1-2GB en disco.
